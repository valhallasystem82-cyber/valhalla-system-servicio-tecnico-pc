VALHALLA SYSTEM V2

1) Abrí index.html para ver la web completa.
2) Abrí admin.html para editarla.
3) La primera vez, admin.html te pedirá crear una clave local (mínimo 6 caracteres).
4) Desde ADMIN podés editar logo, fondo, colores, textos, iconos, servicios, productos, sistemas, galería y contacto.
5) Esta versión funciona directamente desde la carpeta, sin servidor, para que puedas probarla.
6) Los cambios locales se guardan en el navegador de esa PC (localStorage).
7) Para publicar de verdad y administrar desde cualquier PC/celular, el siguiente paso es conectar Firebase Authentication + Firestore + Storage.
